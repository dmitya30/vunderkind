# vunderkind

Production-лендинг Школы скорочтения Васильевой Л.Л. в Санкт-Петербурге.

- Сайт: https://supermozg.pro/
- Актуальный контекст: [`docs/PROJECT.md`](docs/PROJECT.md)
- Правила для AI-агентов: [`AGENTS.md`](AGENTS.md)

Стек: HTML, CSS, vanilla JavaScript.  
Деплой: GitHub Pages через GitHub Actions при push в `main`.

Контент production-сайта является источником истины. Не заменяйте его текстами
из старых документов или истории Git без прямого задания.
